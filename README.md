# luminary — Elite Dark Portfolio Showcase

A sophisticated, dark-themed portfolio project designed to showcase high-end design skill and technical precision through high-impact visual delivery.

## 🚀 Key Features
- **Elite Dark Aesthetic:** Sophisticated color palette with radial glows and noise textures.
- **Micro-interactions:** Custom animations and transitions throughout the experience.
- **Case Study Focused:** Structured to present projects as in-depth design stories.
- **Premium UI:** Every pixel earned its place in this high-end design showcase.

## 🛠️ Tech
- HTML5
- CSS3 (Custom Variables)
- Vanilla JavaScript (ES6+)
